**神经网络的结构**：
输入层x->隐藏层->输出层y
y = model(x)也就是前向传播
隐藏层中有多个神经元，每个神经元经过公式：a=h(wx+b)，h（x）是非线性激活函数（因为经过神经元变换之后本质上就是线性变换，要引入非线性相关来使网络更好地学习到更复杂的信息，学习更深度），w和b是参数（w是权重矩阵，b是偏置），就是将输入乘上权重并求和再加上偏置，最后通过激活函数得到输出。
希望通过模型的到最优参数最终得到输出y

**梯度消失**：导数无限接近于0
因为涉及到求损失函数的最值，求最值点自然用到导数，然后再根据最值点去确定最优参数

**神经元死亡**：导数为0，参数不更新

**损失函数**：通过损失函数计算前向传播输出的预测结果与真实标签(label)之间的误差，误差越小预测越准确，模型越好。

**回归**：是一种监督学习方法，其目标是**预测一个连续的数值输出**（因变量），基于一个或多个输入变量（自变量）。
- **通俗理解**：它不是让你“选类别”（猫还是狗），而是让你“填数字”（房价是多少、明天温度多少度）。
- **生活中的例子**：
    - 根据房屋面积和地段，预测**价格**（如500万）。
    - 根据学习时间，预测**考试成绩**（如85分）。
    - 根据广告投入，预测**销售额**（如1200万元）。

**回归用MSE均方误差损失函数，分类用crossentropy交叉熵损失函数就行**

**1. 均方误差损失函数**
$$
J(x)=\frac{1}{2m}\sum_{i=1}^{m}\left(f(x_i)-y_i\right)^2
$$
- f(x_i)是前向传播的输出结果，因为输入x已经确定之际上就相当于f(w,b)
- y_i是真实值标签
- 加上1/2是为了求导，有没有皆可

**反向传播**：从输出端的损失函数开始，用**链式求导法则从后往前**一层层计算“损失关于每个参数（w和b）的偏导数（即梯度）”，然后沿  **梯度下降方向**更新参数。（ **梯度下降**就是取梯度的**反方向**，就是让损失函数值**减小得最快**的方向。因为只有朝这个方向调整 w和 b，损失函数才会**减小**）

- **梯度下降算法**：
$$
w_{new} = w_{old} - \eta \cdot \frac{\partial J(x)}{\partial w}
$$
    -  梯度指向损失**上升**的方向，取**反方向**使损失减小。
    - **梯度方向**：告诉了你**朝哪个方向走**（是往东还是往西）
    - η（学习率）控制步长，步长指的就是**参数 w 在这一次迭代中，在数轴上移动的绝对距离**，告诉你**每一步迈多大**
    参数b同理。

数学中：
- 如果某点导数 f′(x)=2（大于0，即梯度为正），说明**增加 x 会让f(x) 变大。
- 为了减小f(x)，我们必须**减小 x**（即往负方向走）。公式：xnew=x−2（减去了一个正数，这就是反方向）。
- 如果某点导数 f′(x)=−3（小于0，即梯度为负），说明**增加 x** 反而会让 f(x) 变小。
- 为了减小 f(x)，我们必须**增加 x**（即往正方向走）。公式：xnew=x−(−3)=x+3（减去一个负数，实际上就是加，这也是反方向）。

深度学习中：
- 梯度是一个**向量**（包含 w 和 b 每个分量的偏导数），比如 ∇J=(2,−3)。
- 这个向量指向了空间中最陡峭的**上坡**。
- 取反方向，就是向量 −∇J=(−2,3)。这意味着：**把 w 减小一点，把 b 增大一点**，此时损失函数下降得最快。

**训练过程**：循环执行：前向传播->计算损失->反向传播->测试

>输入层

在图像识别任务中，输入层通常接收RGB三通道彩色图像，这些图像会以高度（H）、宽度（W）、通道数（3）构成的三维张量H×W×3形式输入到网络中。这三种通道分别对应图像的红色通道R、绿色通道G、蓝色通道B。每一个通道本身又是由一个二维的像素矩阵组成的，矩阵当中每个像素的数值通常在0到255这个范围之间，这个数值就代表了该位置上的颜色强度，越小颜色越深。

>全连接层

全连接层的每个神经元都与上一层的所有神经元相连接，因此输入必须是**一维特征向量**。如果数据是多维的（如图像、时序序列），必须通过 `Flatten` 或 `Reshape` 操作将其展平。将图像展平为一维向量后，像素之间的空间关系（邻近、边缘、形状等）完全丢失，同时每一层的神经元都与上一层的所有神经元全连接，导致参数量巨大。参数过多容易过拟合，可以通过Dropout操作来防止过拟合，减少一些参数的更新而 加速训练。
例如图像经过卷积和池化操作后变成了16×5×5，则全连接层的输入就有16×5×5=400个(x1,x2x,...,x400)，如果全连接层输出的大小为120，则对应有120个神经元，因为每个神经元得到一个输出。
因为最后要做的任务是回归或者分类，卷积部分输出是特征图，回归任务最后要的是一个值，分类任务最后要的是不同类别对应的概率，所以需要全连接层得到每个类别的预测概率（分为10个类别则需要最后全连接层输出的大小就为10）
![[Pasted image 20260829205852.png]]
例如：
- 输入维度：`(batch_size, input_features)`
- 其中 `input_features` 就是展平后的一维向量长度

**正常训练流程**
先把 $x$ 通过网络前向传播，然后把误差反向传播以决定如何更新参数让网络进行学习。
**Dropout 流程**
1. **随机删除神经元**  
   首先随机（临时）删掉网络中一半的隐藏神经元，输入输出神经元保持不变。
2. **前向传播与反向传播**  
   然后把输入 $x$ 通过修改后的网络前向传播，然后把得到的损失结果通过修改后的网络反向传播
3. **更新参数**  
   小批训练样本执行完这个过程后，在没有被删除的神经元上按照随机梯度下降法更新对应的参数（$w, b$）
4. **重复过程**  
   然后继续重复这一过程
例如设置dropout = 0.2 则表示每轮训练随机抽20%的神经元失活。

>卷积层（使通道变大或变小）

卷积层中的卷积核就是前面说的权重矩阵w
    卷积运算开始时，卷积核会从输入特征图的左上角起始位置开始，与覆盖区域内的对应元素进行逐个元素相乘，并将所有乘积结果累加，同时叠加偏置项，最终得到输出特征图相应位置的像素值。数学中卷积运算就是指在输入矩阵上滑动卷积核并计算卷积核权重与输入矩阵的对应区域之间的点积。
    步幅则决定了在卷积运算期间卷积核在输入矩阵上移动的程度。步幅为1意味着卷积核一次移动一个像素。
    填充是指在边缘像素点周围填充“0”，使得输入图像的边缘像素也可以参与卷积计算，保留图片边缘信息。
![[Pasted image 20260829154344.png]]
因此输出特征图尺寸与输入特征大小、卷积核大小、填充大小和步幅有关，其计算公式如公式（2-1）所示：
$$O = \frac{I - K + 2P}{S} + 1$$
其中，O是指输出特征图的大小（高或宽），I是指输入特征图的大小，K是指卷积核的大小，P是指填充大小，S是指步幅。

**多通道卷积运算**：每个卷积核与对应的输入通道分别卷积，然后将每个通道的卷积结果进行求和。
口诀：
 **通道一致算内积，多个内核出多道**
- 卷积核的通道数 = 输入的通道数
- 卷积核的个数 = 输出的通道数

**卷积层和全连接层（隐藏层，除了池化层）之后都要接激活函数，输入层和输出层不用激活**

>池化层（使特征图变小，也就是降维）

常见的池化操作类型有最大池化和平均池化。最大池化是指从特征图的每个局部区域取最大值作为输出，因此保留了每个区域中最突出的特征。平均池化则是计算每个局部区域的平均值，而不是最大值，平滑了特征图的同时，又为输入提供了更全局的表示。
感受野算法是每步池化的区域大小，可以理解为每步运算时运算区域的尺寸。

# LeNet（LeNet-5）网络结构

LeNet（LeNet-5）由两个部分组成：

- **特征提取部分**：由两个卷积层和两个平均池化层组成
- **全连接层**：由三个全连接层组成
LeNet-5中的5是指模型中只有5个有参数的层，两个卷积层和三个全连接层。非线性激活函数使用sigmoid

---

## 模型单元结构

一个卷积层、一个sigmoid激活函数、一个池化层

---

## 数据的传输

| 层类型 | 输入维度 | 输出维度 |
|--------|----------|----------|
| 卷积层 | 4维数据（B, C, W, H） | 4维数据（B, C, FW, FH） |
| 全连接层 | 2维数据（B, L） | 2维数据（B, FL） |

### 维度说明

- **B**：Batch Size（批量大小）
- **C**：Channel（通道数）
- **W、H**：Width、Height（输入的宽和高）
- **FW、FH**：Feature Map Width、Feature Map Height（特征图的宽和高）
- **L**：输入特征长度
- **FL**：输出特征长度
# AlexNet 与 LeNet 的对比

AlexNet和LeNet的设计理念非常相似，但也存在显著差异，采用多CPU并行训练模式。

## 主要差异

1. **网络深度**
   - AlexNet比相对较小的LeNet5要**深得多**

2. **网络结构**
   - AlexNet由**八层**有参数的层组成：
     - 五个卷积层
     - 两个全连接隐藏层
     - 一个全连接输出层
    此外来由三层最大池化层

3. **激活函数**
   - AlexNet使用**ReLU**而不是sigmoid作为其激活函数
1. **池化操作**
   - 在CNN中使用重叠的最大池化而不是平均池化

>图像增强——PCA（加滤镜）

**PCA 图像增强流程：**
1. **归一化处理**  
   将图片按照 RGB 三通道进行 normalization 处理，均值为 0，方差为 1
2. **矩阵展平**  
   将图片按照 channel（通道） 展平成大小为 $(H \times W, 3)$ 的矩阵
3. **计算协方差矩阵**  
   计算展平后的矩阵的协方差矩阵，协方差矩阵的大小为 $(3, 3)$
4. **特征分解**  
   对协方差矩阵进行特征分解，得到对应的特征向量 $(3, 3)$ 和特征值 $(3, 1)$
5. **抖动处理**  
   设置一个抖动系数，该抖动系数是一个 $(3, 1)$ 大小的矩阵，里面的元素是随机值  
   利用抖动系数和对应的特征进行相乘，依然得到一个 $(3, 1)$ 大小的矩阵  
   对该矩阵进行转置并和特征向量进行矩阵相乘，得到一个 $(3, 1)$ 大小的矩阵
6. **增强图像**  
   利用上述最后计算出来的 $(3, 1)$ 大小的矩阵，其中的 3 个值分别加到原图像的 R、G、B 三通道上，就是最后得到的增强的图像

>LRN正则化（局部归一化）

**局部归一化作用**
对局部的值进行归一化操作，使其中比较大的值变得相对更大，增强了局部的对比度，在 AlexNet 中有 1.2 个百分比左右的提升。
**公式**
$$b_{x,y}^i = a_{x,y}^i \left( k + \alpha \sum_{j = \max(0,i-n/2)}^{\min(N-1,i+n/2)} (a_{x,y}^j)^2 \right)^{-\beta}$$

| 参数       | 含义     | 说明                                      |
| -------- | ------ | --------------------------------------- |
| **ai_x,y | 输入值    | 位置 (x,y) 处第 ii个通道的激活值（卷积后的输出）           |
| **bi_x,y | 输出值    | 归一化后的结果                                 |
| **i**    | 当前通道索引 | 表示正在处理第 ii个特征图（通道）                      |
| **N**    | 总通道数   | 该层的总特征图数量                               |
| **n**    | 邻域大小   | 参与归一化的相邻通道数量（通常为奇数）                     |
| **j**    | 邻域通道索引 | 从 max⁡(0,i−n/2)到 min⁡(N−1,i+n/2) 范围内的通道 |
| **k**    | 常数偏置   | 防止分母为 0，同时控制归一化强度                       |
| **α**    | 缩放系数   | 控制邻域平方和的权重                              |
| **β**    | 指数系数   | 控制归一化的非线性程度（越靠近 1 越强）                   |
| **x,y**  | 空间位置   | 特征图上的像素坐标（高度和宽度方向）                      |
求和部分表示在相邻的 n 个通道上，同一位置 (x,y) 的激活值平方求和

**流程**
1. **设置超参数**  
   手动设置的超参（$k$, $\alpha$, $\beta$, $n$），若n=2则取旁边的两个值求平方和，旁边没有值则用0填充。
2. **计算归一化值**  
   对每个值利用公式计算局部归一化后的值
